# Security Policy

KidView's security goals, threat model, and current protections are
documented in [`docs/Security.md`](docs/Security.md) — start there.

## Reporting a Vulnerability

This is a personal, non-commercial project with no dedicated security
team or bug bounty. If you find a security issue, please open a private
report via GitHub's "Report a vulnerability" button on the Security tab
of this repository (Security → Advisories → Report a vulnerability)
rather than a public issue, so it can be addressed before details are
made public.

## Scope

This project is not intended for production/commercial deployment and
has no SLA for fixes. Reports are still welcome and appreciated.
