# iOS Workspace

Create the future Xcode project for KidView in this directory.

Recommended starting point:

- App name: `KidView`
- UI: SwiftUI
- Web playback wrapper: `WKWebView`
- Child lock flow: Guided Access aware, parent-initiated

Suggested initial layout:

- `KidView.xcodeproj`
- `KidView/`
- `KidViewTests/`
- `KidViewUITests/`
- `Assets/`
